# vk-chain

**Цепочки рукопожатий и граф друзей ВКонтакте**

[![Python 3.9+](https://img.shields.io/badge/Python-3.9%2B-blue?logo=python)](https://python.org)
[![License: MIT](https://img.shields.io/badge/License-MIT-green)](LICENSE)

Найди, через сколько людей ты связан с любым пользователем ВКонтакте.  
Визуализируй сеть друзей прямо в браузере — интерактивно, уровень за уровнем.

</div>

---

## Что умеет

| Скрипт | Что делает |
|---|---|
| `vk_chain.py` | Находит кратчайшую цепочку между двумя людьми (BFS), ищет родственников и однофамильцев |
| `explore.py` | Интерактивный визуальный граф — строится прямо в браузере, загружает уровень за уровнем |

---

## Установка

**Python 3.9+** и **pip**:

```bash
git clone https://github.com/FalconTechDev/vk-chain
cd vk-chain
pip install requests
```

Больше зависимостей нет. `explore.py` использует только стандартную библиотеку + `requests`.

## Быстрый старт

### 1. Получи токен VK

Зайди на [vk.com/dev/access_token](https://vk.com/dev/access_token) и получи `access_token` с правами `friends`.

Сохрани его один раз:

```bash
python vk_chain.py --token ТВОЙ_ТОКЕН --save
```

Токен сохраняется в `~/.vk_chain_token` — в репозиторий он **никогда не попадает**.

---

### 2. Найти цепочку между двумя людьми

```bash
python vk_chain.py <user1> <user2>
```

`<user1>` и `<user2>` — это VK ID, короткое имя (`durov`) или ссылка `vk.com/durov`.

**Примеры:**

```bash
# По ID
python vk_chain.py 1 123456789

# По коротким именам
python vk_chain.py durov id123456

# Найти и открыть HTML-отчёт
python vk_chain.py durov id123456 --html
```

**Результат:**

```
Цепочка (3 рукопожатия):
  Павел Дуров → Иван Иванов → Мария Петрова → Алексей Сидоров
```

---

### 3. Найти родственников и однофамильцев

```bash
python vk_chain.py --relatives <user>
python vk_chain.py --relatives durov --html   # + открыть отчёт в браузере
```

Ищет людей с совпадающей фамилией среди друзей и друзей друзей.  
Поддерживает транслит (`Ivanov` = `Иванов`) и корень фамилии (`--stem`).

---

### 4. Визуальный граф в браузере

```bash
python explore.py
```

Откроется браузер с интерактивной сетью:

- Введи имя или ID любого пользователя
- Граф строится уровень за уровнем — сначала все друзья, потом их друзья
- Между уровнями — пауза с обратным отсчётом (5 секунд по умолчанию)
- Узлы расположены кольцами без наложений
- Есть кнопки **Пауза / Продолжить / Стоп**
- Слайдеры для настройки скорости загрузки

```bash
python explore.py --port 5001   # другой порт
```

## Все флаги vk_chain.py

```
Поиск цепочки:
  <user1> <user2>           найти кратчайший путь между двумя людьми

Родственники:
  --relatives <user>        искать родственников и однофамильцев
  --stem                    искать по корню фамилии (Иванов → Иван*)
  --deep                    углублённый поиск (дольше, но больше результатов)
  --html                    сохранить и открыть HTML-отчёт

Авторизация:
  --token <tok>             VK access_token
  --save                    сохранить токен в ~/.vk_chain_token

Настройки:
  --depth <n>               глубина поиска (по умолчанию 6)
  --delay <sec>             задержка между запросами к VK API (0.35 сек)
  --no-cache                не использовать кэш друзей
  --json                    вывод в JSON
  -v / --verbose            подробный вывод
```

## Как работает

### Цепочки

Используется двунаправленный BFS: поиск ведётся одновременно от обоих пользователей навстречу друг другу. Встреча в середине — это и есть цепочка.

При первом запросе друзья каждого пользователя сохраняются в `friends_cache.json`. Повторные запросы к уже известным людям не делают вызовов к API.

### Визуальный граф

`explore.py` запускает локальный HTTP-сервер и открывает браузер. Граф строит [vis.js](https://visjs.org) — без физической симуляции, узлы расставляются по кольцам вручную. Загрузка идёт волнами: сначала все друзья центрального узла (уровень 1), потом всех из уровня 1 (уровень 2) и т.д.

## Что не публикуется в репозиторий

```
friends_cache.json     — личные данные о друзьях
relatives_cache.json   — личные данные
photos/                — фотографии
relatives_reports/     — HTML-отчёты с именами людей
~/.vk_chain_token      — токен VK
*.log                  — логи
```

Всё это перечислено в `.gitignore`.
